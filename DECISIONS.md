# Engineering Decisions — Compressor Train Sizing

The calls that shaped the workbook and the web calculator: what was decided, what was rejected, and
why. Sources for each topic are in `SOURCES.md`.

*Built by Joshua Sharpes, EIT, with AI assistance (Claude) for drafting, coding and checks. Scope,
method selection, validation criteria and the corrections below are his.*

## Approach

**Decks first, then a workbook, then the web tool.** The method comes from Joshua's two compressor
decks, his heat-exchanger heuristics deck and his economics project's payback method. The workbook
is generated by a script from those sources, so the method lives in one place. The web calculator
re-implements the same chain independently, and a "download personalized spreadsheet" button hands
the user's inputs back into the workbook so every step can be inspected.

**Selection is automatic, with an override.** Compressor type follows from flow and adiabatic head,
not preference, so the tool selects the type and the efficiency method itself and lets the user
override either one.

## Stage count

**Optimize the stage count, don't just screen one.** The economics sheet sweeps 1–6 stages and costs
the compressor and intercoolers each stage count actually implies. Lighter options (a marginal
check on one chosen N) were considered and rejected in favor of a full cost-optimized stage count.

**Every cost component visible.** A single total-capital number per stage count was tried first and
dropped: you couldn't tell what each stage count cost. Each component now has its own column.

**Type re-derived per stage count.** Adding stages lowers the head per stage, which can move the
operating point into a different compressor type. The sweep re-checks the type at every N.

**Discharge temperature as a range, not one number.** The deck gives allowable ranges because the
real limit depends on lubricant and gas. The flag is three-tier: OK, CAUTION (check the vendor
rating) and EXCEEDS (add a stage).

## Cost basis

**Seider for equipment cost, Peters & Timmerhaus for the payback test.** The two textbooks' correlations
were compared side by side (`compressor_cost_comparison_PT_vs_Seider.pdf`). Seider was chosen for
purchase cost: explicit equations, sized on the horsepower the workbook already computes, and the
intercooler costed in the same chapter. P&T's payback structure was kept, because Seider's own
payback formula assumes new sales revenue, which a power-saving retrofit doesn't produce.

**Refuse rather than fabricate.** Seider gives cost equations only for centrifugal, reciprocating and
screw compressors. Other types show "n/a, outside correlation coverage" instead of a borrowed fit.

**Current tax law.** Tax defaults to 21 % (post-2017 federal rate, no Texas corporate income tax),
not Seider's pre-2018 graduated table, which would overstate the tax shield.

## Errors caught by independent checks

The workbook's formula chain was re-implemented in Python and compared, and the workbook was opened
in Excel to confirm recalculation. That caught:
- an inverted ηp ↔ n relationship;
- a stage count wrongly marked infeasible by a text check;
- a nonsensical negative payback when adding a stage makes the compressor cheaper (Seider's steep
  power exponents allow this); it now reads "FREE: cheaper capital and lower operating cost";
- a spreadsheet library that silently stripped all cell formatting on download, replaced by a direct
  cell patch.

## Stated simplifications (Class 5, ±30–50 %)

Constant polytropic efficiency across the sweep; Fig. 10-64 boundaries read by eye; intercooler
area from an assumed U, not a thermal design; depreciation life equal to the evaluation period.
